# 官方运行时接入与适配

## 接入基线

尚未取得官方交付包；以下为实施清单，不是安装完成记录。以一个分支和一个版本组合起步，优先纯 Lua/多端分支，但最终依据可获得的许可、工具与稳定版本确定。历史 1208 包不自动成为首期选择。

M0 必须登记：产品分支、获取来源/日期、许可范围、引擎/客户端/DB/工具版本、文件 SHA-256、是否允许本地/测试服/正式服、是否依赖联网授权、支持 OS/SQL、工具与反外挂/CDN 条件。安装包放受控制品库，Git 只记录无密钥元数据。

## 环境清点与首次启动

1. 在隔离 Windows VM 上验证文件哈希并保存原始交付包；使用专用测试凭据和测试资源。
2. 按官方兼容表配置 Windows、SQL、驱动、运行库与授权网络，不预选未经支持的最新版本。
3. 建立进程列表：可执行路径、版本、职责、启动顺序、依赖、服务账号、日志路径、退出信号。
4. 建立端口列表：监听进程、方向、调用者、绑定地址、是否公开、是否能改端口；不复制教程默认端口到生产。
5. 建立配置清单：目录、配置项、编码、路径大小写、生成方式、敏感字段、恢复方法。
6. 依次验证数据库/角色、登录、网关、M2、客户端实际连接，顺序以官方包为准；保存日志与失败信息。
7. 创建测试角色，移动/战斗/死亡/掉落/穿戴/重登，确认保存；若包提供多个客户端，验证至少两端同服。
8. 冻结首个环境 BOM，保留原始包与最小差异，不将成功启动等同稳定性或承载验收。

证据：版本矩阵、脱敏连接图、配置模板、启动日志、角色前后快照、重复启动/停止结果、已知限制。

## 能力探针

| 探针 | 必须观察的结果 | 失败时的处理 |
|---|---|---|
| Lua 版本/require | 支持的语法、加载目录、模块缓存、缺模块行为 | 收紧兼容子集，禁止升级引擎内置 Lua |
| 编码 | 中文、特殊字符、路径在加载/网络/落库后的值 | 严格转换；不可编码内容阻止发布 |
| 入口与定时器 | 回调线程、频率、重载后重复注册、异常处理 | 集中注册/解绑，不依赖全局循环 |
| 对象生命周期 | 玩家离线/切图/重载后句柄有效性 | 只存稳定 ID，使用时重新查询 |
| 消息 | LuaNetMsg/SubmitForm 的参数、大小、顺序与返回 | 选择已证实方式，建立固定路由白名单 |
| HTTP | HTTPS、超时、是否阻塞、回调线程、重试、证书、认证头 | 无安全且非阻塞路径时改桥接方案或暂停功能 |
| 资产写入 | 扣除/发放是否原子、保存时点、唯一业务键、可查询结果 | 不能证明时限制高价值操作并保留待核对状态 |
| UI | GUI 控件、导出格式、PC/触屏事件、销毁/卸载 | 提供少量已验证 UI 控件封装 |
| 热更新 | 包格式、校验、旧客户端行为、回退、断点/静默策略 | 降低自动化范围，不自造客户端未知格式 |
| 工具 | 表格/资源工具版本、命令行、退出码、确定性 | 明确人工步骤，归档输入输出与报告 |
| 跨服 | 唯一归属、返回/断线、资产处理、查询/恢复 | 在 M6 前不开放复杂资产玩法 |

能力矩阵中 `documented`、`mock_verified`、`runtime_verified` 分别记录；当前模板各项 `unverified`。探针要锁定 BOM、步骤、期望/实际、日志路径，不能用另一个版本成功的记录覆盖。

## ER 适配契约（拟建）

| API | 意图 | 约束 |
|---|---|---|
| `ER.Runtime.get_player(player_id)` | 查找当前在线对象 | 返回失效错误，不能持有长期官方对象 |
| `ER.Runtime.get_balance(player_id, currency)` | 读取游戏余额 | 只读，不相信客户端余额 |
| `ER.Runtime.execute_reward(command)` | 受控奖励命令 | 必须返回持久结果证据或 unknown；实现待探针，不是已具备原子 API |
| `ER.Runtime.send_message(player_id, message_id, payload)` | 业务消息传输 | payload 校验、版本与大小约束 |
| `ER.Runtime.register_event(name, handler)` | 事件接入 | 每个生命周期唯一注册，记录可卸载范围 |
| `ER.Runtime.schedule(name, interval, handler)` | 官方定时器适配 | 以官方时间单位和线程模型为准 |
| `ER.Runtime.request_platform(request)` | 受控外围调用 | 不阻塞世界线程；认证/超时策略明确 |

统一返回结构拟定为 `{ok, code, data, retryable, evidence_id}`；`unknown` 不能当作失败后自动重试。错误分为校验失败、对象离线、版本不支持、容量限制、依赖故障、结果未知。重试必须由调用方按操作语义决定。

## 热重载与升级

先声明哪些模块可热重载：静态展示/无状态规则优先；资产事务、注册入口、订单状态、未完成任务不可随意换代码。重载采取停止新请求 → 等待/登记在途操作 → 卸载支持的回调 → 新模块校验 → 启用；没有可靠卸载机制时采用维护窗口重启。

升级官方版本必须在隔离环境执行全量能力回归和 DB 备份恢复，不单独替换 M2/客户端/某张配置表。变更记录写入 BOM 与能力矩阵，不能只登记“引擎更新”。
