# 测试、容量与验收体系

## 测试证据等级

1. 静态：源码/表格/schema/资源/BOM 校验。
2. 离线：领域逻辑与 fake runtime、模拟消息/错误、平台事务测试。
3. 官方集成：真实锁定引擎/客户端/数据库/工具，验证参数与保存语义。
4. 预发布：完整拓扑、多端、资源/CDN、渠道沙箱、部署与恢复。
5. 封测/生产：真实运行观察与授权范围内测试，发布前条件未通过不能靠生产补验。

每份报告记录环境/日期、BOM、源码、数据集、步骤、预期/实际、失败证据、已知限制。离线通过不等于官方 API 可用；文档完成不等于任何运行场景通过。

## 必须覆盖的场景

| 领域 | 正常与边界 |
|---|---|
| 账号/角色 | 创建、登录、重登、多端/同账号策略、切服、失效身份 |
| 世界 | 移动、碰撞、寻路、切图、传送、坐标越界、断线 |
| 战斗 | 普攻、技能、Buff、伤害/冷却、怪物 AI、死亡/复活 |
| 资产 | 掉落、拾取、背包满、穿戴、仓库、合成失败、断线保存 |
| 社交/经济 | 组队、行会、邮件、交易/摆摊/拍卖、重复确认 |
| 玩法 | 任务、NPC、活动时间边界、重复领取、配置切换 |
| 客户端 | 打开/关闭 UI、回包迟到、重连、后台/前台、安全区域 |
| 发布 | 首包、热更、微端/静默、断下载、资源缺失、旧客户端 |
| 跨服 | 进入、返回、断线、重启、重复请求、唯一归属与资产 |
| 平台 | 支付回调/查询、重复/乱序/迟到、补单、CDK、GM 越权 |
| 恢复 | M2/DB/平台故障、备份恢复、升级失败、回滚后版本兼容 |

玩法手感通过固定地图/帧率/输入录制进行人工体验与可量化时序对照。历史规则只对明确兼容范围建用例，不声称全量传奇生态完全一致。

## 契约与故障测试

消息 ID/字段/方向/版本、配置公共投影、资源路径/大小写、编码往返、官方 API 能力、DB schema 与 BOM 兼容是发布硬门槛。

奖励链路在发命令前、游戏执行前、资产变化后、持久标记前后、回应前后、平台记录前后分别注入崩溃/超时。确认同一命令不会增发且不会静默丢失；不能判断的进入 UNKNOWN 并停止自动重试。官方无法提供相关语义时结果是“能力不满足”，不是“测试不充分但可上线”。

数据库故障验证游戏是否停止/继续、操作是否部分保存、重登是否回退；跨服故障验证单一写归属，不能只验证返回页面。支付回调金额/币种/签名不匹配、重复/重放、订单关闭/退款与 worker 租约到期均有测试。

## 机器人与压测

优先官方测试客户端/受支持工具。若官方私有协议不能合法且可靠自动化，先控制真实测试客户端或做平台/桥接压测；不为了压测逆向私有协议，也不把 HTTP 压测结果当作游戏承载。

目标梯度参考：100、300、500、800 在线；50、100、200 同屏集中战斗，按环境能力逐级推进。是测试档位，非保证支持人数。

场景分别测登录峰值、空闲/移动、怪物寻路、技能/Buff 密集、掉落拾取、沙城类集战、数据库延迟、跨服峰值、热更下载峰值。每场建议：热身 10 分钟、稳态 30 分钟、峰值与恢复 10 分钟；正式 soak 时长依 M3 基线制定，至少加入长时间稳定运行场景。若指标恶化则停止增压并保留失败点。

报告需含硬件/OS/网络、BOM、在线/同屏/怪物数、行为分布、工具/脚本、实际输入速率、p50/p95/p99、错误/丢包/积压、客户端帧率/内存、服务资源与恢复时间。无法获得内部 tick 时如实报告，使用端到端响应做代理。

## 验收门槛

| 里程碑 | 最小证据 |
|---|---|
| M0 | 版本/许可/进程/端口清点，锁版启动与角色保存，能力缺项列表 |
| M1 | 干净 Windows 环境复现，BOM、启停、健康检查、实际备份恢复 |
| M2 | 好/坏样本校验、构建追踪、官方转换、测试部署与兼容回滚 |
| M3 | 垂直切片完整游玩重登、UI/消息、一次热更、沙箱链路与报告 |
| M4 | 核心玩法规格和边界回归、经济规则、无未解决高危资产差异 |
| M5 | 已交付各目标端设备/弱网/包/资源链路实测，渠道与发行条件清单 |
| M6 | 跨服故障/归属、支付幂等/对账、GM/RBAC、压测和恢复演练 |
| M7 | 封测缺陷收敛、发布/回滚演练、业务与运维验收证据 |

## 缺陷与发布阻断

P0：资产复制/丢失、越权、不可恢复数据、批量登录失败；立即停止相关发布/写操作。P1：核心链路失败、无法安全回滚、关键端崩溃；阻止对应版本发布。P2：非核心体验/性能缺陷；有范围与处置记录。优先级用于缺陷管理，不等同任务优先级。

退出条件以行为和证据为准，不以“测试数量足够”代替。文档改动只检查相关链接、结构和一致性；实施时测试覆盖真实风险与接口，不为镜像实现增加无效测试。当前尚未实现或执行上述软件测试。
