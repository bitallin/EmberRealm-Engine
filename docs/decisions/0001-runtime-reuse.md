# ADR-0001：第一阶段复用官方运行时

- 日期：2026-10-08。
- 状态：已采纳；实现未开始。
- 依据：用户附件后半部分明确优先 Lua、M2、已有能力和最少重写。

## 背景与候选

完全自研能获得底层控制，但原文评估为多年 MMO 平台研发，缺少当前交付包、团队和实际约束证据。直接散落使用官方 API 起步快，却会扩大供应商耦合；只做外挂平台而不形成工程契约也无法解决错配与发布问题。

## 决定

取得官方许可/交付后复用 M2、网关、数据库链路、客户端与工具。自有代码建立 ER runtime 适配、数据/消息 schema、Lua 玩法、UI、BOM、校验/构建/部署、业务平台和观测。玩法依赖自有契约，官方差异集中到适配层；首期 PC 切片，多端随后。

## 后果

首期属于官方内核上的平台，不能宣称完全自主或底层开源。许可、分支、工具、非公开持久化语义构成外部依赖。所有关键能力先探针后实施，资产能力不足时缩小功能而非伪造原子保证。

完整独立内核不包含在当前工作量内。经真实性能/发行/安全约束触发后，提交替换提案，用已有自有契约和行为库验证整组替换，不能把原文“未来可替换”视为现在应重写。
