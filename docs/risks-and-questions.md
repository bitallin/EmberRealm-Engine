## 待决事项与现行默认

| 事项 | 当前可继续使用的默认 | 决定时点 |
|---|---|---|
| 最终官方分支/版本 | 倾向纯 Lua/多端，以可获得稳定包为准，不填真实版本号 | R01 |
| Windows/SQL 版本、硬件/端口 | 不预填，按兼容表与清点结果 | R01/ENV01 |
| 客户端交付范围 | PC 优先、Android/iOS 后续，H5 可选 | R01/M3 范围确认 |

| 是否已有成熟底板 | 未提供，按空项目新建工程与样例，不复制未知底板 | R01/V01 |
| 平台/工具技术与仓库托管 | Python 工具、必要自有模块 Go/PG 拟定；GitHub 托管已完成，CI 待选 | T01/P01/T08 |
| 首版内容与容量 | 一个职业/三地图切片；压测档位不是 SLA | SPEC01/M3 前 |
| 内置系统覆盖/配置/差异 | 不重建原生机制；待锁版逐系统确认 | R07/对应 V/G 任务前 |
| 官方平台服务与自有模块分工 | 先验证并复用，必要映射/对账/差异模块才自研 | R08/对应 P/C 任务前 |
| 目标发行地区/渠道/付费方式 | 沙箱先行，真实付费与发行条件单独验收 | P03/C04/M6 |

上述默认支持继续做文档、契约、工具和离线逻辑；不能代替官方许可、环境、账号或实际用户授权。没有必要为当前文档任务等待这些答案，后续推进到对应节点再处理具体依赖。

## 风险闭环

风险变成故障时关联任务、BOM、日志和报告；修复后重放失败场景并记录剩余限制。新增或关闭风险须同步进度与工作日志；关闭的依据是验证证据，不是“计划中已考虑”。
