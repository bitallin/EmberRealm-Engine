# 烬界引擎 · EmberRealm Engine

**以余烬，铸新界。** / *Forge worlds from embers.*

烬界是面向传奇类游戏的运行时集成、Lua 开发、内容生产、发布与运营平台。第一阶段采用附件中的复用路线：在取得相应交付包和授权后，复用 996 M2、网关、数据库服务、客户端及官方工具，建设可追踪、可测试、可回滚的工程体系。

这阶段的成果是基于官方内核的平台；完整自主内核属于后续独立立项范围。项目代号为 `Project Ember`，简称 `ERE`，Lua 命名空间为 `ER`。
